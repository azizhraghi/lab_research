
  # LRSTE frontend

  React/TypeScript frontend for the LRSTE laboratory workbench. See the root README for backend setup, authentication, scope and verification. Design provenance: the original UI bundle came from the Figma project identified in ATTRIBUTIONS.md and the original design link https://www.figma.com/design/Z8SUwazaGtswf1KnT4ACT1/AI-Research-Laboratory-Platform.

  ## Running the code

  Run `npm ci` to install the locked dependencies.

  Run `npm run dev` to start the development server.
  Run `npm run typecheck` and `npm run build` to verify changes.
